vga-rom-8x8.bin — 8x8 CGA/VGA text font (256 glyphs x 8 rows, 1 byte per row, MSB = leftmost pixel).

Public Domain.

Codes 0x00-0x7F are from Daniel Hepper's font8x8 (font8x8_basic.h), itself based on the
IBM public-domain VGA fonts (via Marcel Sondaar / dimensionalrift). The source bytes are
LSB-first (bit 0 = leftmost); they were bit-reversed to MSB-first when building this binary.
Codes 0x80-0xFF are downsampled (every other row) from the committed 8x16 VGA font as a fallback
for CP437 high characters. Used by the BIOS for INT 10h character output in CGA graphics modes
(4/5/6) — see src/bios.js drawGlyphCGA. Rebuild: see the build script in the commit history.

Source: https://github.com/dhepper/font8x8 (Public Domain)
