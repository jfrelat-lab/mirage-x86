OASIS — images of the period PC

An OASIS image is a recipe, not an archive: the world a program needs (DOS, Linux user space or Win32, all answered in JavaScript), the machine, and layers of files fetched from where their authors published them — Debian's archive, idgames, the examples of this repository. Nothing below is copied into MIRAGE; each layer says where it comes from.

node tools/oasis.mjs serve --open          every image, in the Machines page, at home
node tools/oasis.mjs run linux/mirage         one image, in a window of its own
node tools/oasis.mjs run linux/debian-bookworm -c 'ls /'      in the terminal
node tools/oasis.mjs pull linux/doom-1994       fetch its layers into ~/.cache/oasis
