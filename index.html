An x86 PC in plain JavaScript.

MIRAGE translates x86 machine code into JavaScript source, one basic block at a time, and lets the browser's own JIT compile it. No WebAssembly, no plug-in, nothing to install.

x86 code → decoder → JavaScript source → new Function → the browser's JIT
WindowsThe Win32 API in JavaScript — no Windows: the demoscene's 4K intros on OpenGL and Direct3D 9, Elevated and Ergon among them, drawn through WebGL2. LinuxLinux's system calls answered in JavaScript — no kernel: a real bash from Debian 12, id's DOOM and Quake on SVGAlib, XFree86 3.3 on an emulated Cirrus card. DOSA DOS written in JavaScript, with its BIOS, XMS, EMS and a DPMI host: drop a .COM or an .EXE on it and it runs at once. DOOM, Heretic, Wolfenstein 3D. Bare PCBIOS, VGA, disks and CD: boots unmodified operating systems from an image — Windows 95 and 98, Linux, the BSDs, FreeDOS.

Programs come as OASIS images: recipes that fetch a program's files from where their authors published them, and say which machine it needs — like a Docker image, for the PC of 1990.

Windows intros, with no Windows

4K and 1K intros of the demoscene, their Win32 API, OpenGL and Direct3D 9 written in JavaScript — no Windows, no Microsoft DLL. Their shaders go to WebGL2 through PRISM. Each one is fetched from scene.org when first run. Every screenshot here was taken by MIRAGE itself, and 🔊 sound marks what was heard playing.

Linux, with no kernel

Linux programs as they shipped — id's games on SVGAlib, XFree86 3.3 and Mesa of 1997 — and the demoscene's Linux intros, from 1K to 256 bytes. Linux's system calls are answered in JavaScript. OASIS images fetch their files from Debian's, idgames' and scene.org's own archives, through a small relay of this site; nothing of theirs is copied here. Every image's recipe →

DOS

Games and demos on MIRAGE's own DOS — a BIOS, XMS, EMS and a DPMI host written in JavaScript, no DOS image. Everything here may be redistributed; each card links to its licence and its source.

Boot

MIRAGE's bare PC starts disks from its BIOS: a whole FreeDOS disk and boot sectors of 512 bytes, to run here, then operating systems taken to their desktop from their own disks. Those disks are not ours to share, so they are screenshots — taken by MIRAGE itself — and the button opens the bare PC set up for that system: boot your own copy, nothing is uploaded.

Bring your own

A DOS program

Open the DOS player and drop a .COM, an .EXE or a whole folder on the page: it lands on drive C:. Type its name at the prompt. Games that need XMS, EMS or a DOS extender (DPMI) are served too.

A disk image or a CD

Open the bare PC, choose a floppy, hard-disk or ISO image from your computer, a processor and an amount of memory, and boot. Nothing leaves your browser, and nothing is written back to the file.

MIRAGE ships no operating system or game from anyone else. Use what you are allowed to use.

What it runs

Operating systemsWindows 3.0, 3.1, 95, 98 and ME to their desktop; Linux 2.2 and 2.4; NetBSD, OpenBSD, 386BSD; MS-DOS and FreeDOS; KolibriOS; booted from a CD with El Torito.
Linux programsi386 ELF (static, PIE, dynamic) and a.out from 1994 to today, on no Linux kernel: Debian 12's bash and coreutils; id's DOOM and Quake on SVGAlib, with their sound; Debian 1.3's gcc 2.7.2 building DOOM; XFree86 3.3 on an emulated Cirrus GD5446 at 800x600, with twm, X DOOM and Debian's X games.
DOS gamesDOOM, Heretic, Quake and Wolfenstein 3D play; dozens of EGA and VGA titles render.
Demos31 of the 32 size-coded intros tried, from 32 bytes to 64 KB.
Not yetWindows NT and 2000, ReactOS, BeOS; the Gravis Ultrasound; a network card, and networking for Linux programs; 64-bit.
